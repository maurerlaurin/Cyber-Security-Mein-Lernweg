## 📅 2026-05-28

**Modul:** Defensive Security Intro
**Was ich gelernt habe:** Defensive Security bedeutet einen Angriff erkennen, identifizieren und stoppen (Containment). Firewall-Regeln können Angreifer-IPs blockieren.
**Neuer Befehl:** -
**Aha-Moment:** Containment als erstes Ziel — nicht Gegenangriff, sondern Schaden begrenzen.

---

## 📅 2026-05-28

**Modul:** Offensive Security Intro
**Was ich gelernt habe:** Mit dirb versteckte Seiten einer Website finden. Angreifer denken wie ein Hacker um Schwachstellen zu entdecken.
**Neuer Befehl:** `dirb http://fakebank.thm`
**Aha-Moment:** Websites lassen oft versteckte Seiten offen — dirb findet sie automatisch.
